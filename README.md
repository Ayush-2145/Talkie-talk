Thhe purpose of this project is to build a real time messaging app that uses websockets to communicate over web beowswers in real time

The tech-stack used in this project is as follows:

BACK-END : 
*Spring-Boot
*Spring WebSockets
*Spring Messaging - The STOMP protocol
*Thymeleaf

FRONT-END :
*Thymeleaf
*JavaScript
*Sock js
*STOMP js
*HTML/CSS
*Bootstrap

(*There may be changes in the Tech-stack during future development)
